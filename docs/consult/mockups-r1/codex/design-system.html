Saurus literatus

A quiet research companion, drawn like a field illustration. The posture stays familiar; the papers tell you what is happening.

All strokes and filled details inherit currentColor. Use academic green on paper, or inherit the surrounding text color. Each state is static and works with reduced motion. Give meaningful illustrations an accessible title; hide decorative instances from assistive technology.

Care is a design decision.

An academic tool should welcome long reading sessions, different ways of navigating, and the occasional late night.

Visible focus

Native links, buttons and disclosure controls work from the keyboard. A skip link leads directly into the notebook.

More than color

Labels and symbols accompany status colors. Pastel themes always carry a written name, with dark text in both modes.

Unhurried by default

No spinning mascots or ambient movement. Reduced-motion preferences also remove smooth scrolling.

Space that adapts

Reading columns keep a comfortable measure. Sidebars yield to the content on smaller screens. Primary controls use 44 px touch targets.
