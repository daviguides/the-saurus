Design System · R1

The Saurus

A reading room, not a dashboard. Paper tones, ink, academic green for action, gold for what's alive. In the dark, aged paper under candlelight.

01

Principles

Every claim has an address.

Citations are the primary UI element, not decoration. Paper · page · paragraph, always visible, always clickable.

You can watch it think.

The pipeline is a visible trace, not a spinner. Green is done, gold is happening now, grey is waiting.

The researcher stays the author.

Serif for the review, sans for the tool. The tool never shouts over the text.

Playful at the edges.

The dinosaur lives in empty states and margins. Inside the pipeline it steps back and lets the data speak.

02

Color

Toggle the theme to see each token resolve. Chip colors are pastel in light mode and deepen to muted jewel tones in dark so text stays legible.
